# LOCKIN Product Requirement Document

## Product Vision
LOCKIN creates a digital study environment where students improve consistency through accountability, collaboration, and AI-powered learning.

## Problem
Students struggle with:
- maintaining focus
- effective revision
- understanding their learning progress

## Target Users
College students:
- Foundation
- Diploma
- University

## Version 0 User Role
Student only.

Students can:
- create profile
- join study rooms
- upload learning materials
- complete AI quizzes
- track progress

## Core Features

### Focus Rooms
Students study together using:
- shared goals
- participant visibility
- Pomodoro sessions

### AI Active Recall
Workflow:

PDF upload
-> AI analysis
-> Quiz generation
-> Feedback
-> Weak topic detection

### Progress Dashboard
Tracks:
- study hours
- completed sessions
- quiz accuracy
- weak topics

- PAL system
