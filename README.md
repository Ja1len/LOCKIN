# LOCKIN

Student Productivity Platform

Version: 0.1 Prototype

## Overview
LOCKIN is a student-focused productivity platform designed to help students study with accountability, maintain focus, learn using active recall, and track academic progress.

Core loop:

Study -> Focus -> Recall -> Improve

## Version 0.1 Features
- Student profile
- Theme customization
- Dashboard
- Pomodoro timer
- Study rooms
- AI PDF quiz prototype
- Progress tracking

## Technology Stack
Frontend:
- Next.js
