# LOCKIN UI Design Direction

## Design Philosophy

Balance:
- productivity
- community
- motivation

LOCKIN should not feel like social media.
It should feel like a digital study environment.

## Theme Modes

### Deep Focus
- dark
- minimal
- low distraction

### Clean Study
- bright
- academic
- organized

### Energy Mode
- colourful
- achievement focused

### Custom Theme
Students select:
- accent colour
- animation intensity

## Main Navigation

Desktop:
- Home
- Rooms
- AI Tutor
- Progress
- Profile

Mobile:
- Home
- Rooms
- AI
- Profile

## Style Reference
Combination of:
- Linear (premium UI)
- Notion (organization)
- Discord (community)
- Duolingo (motivation)
